# Configuration

grip reads configuration from four places; the higher in the list wins.

| Option | Default | Description |
| --- | --- | --- |
| `remember_passes_hours` | `24` | How long a passed diff is remembered. |
| `fail_open` | `false` | Let the commit through when the provider errors out. |

Set the options you want and commit the file, so the whole team shares the same bar.
